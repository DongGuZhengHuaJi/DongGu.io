上一篇文章我们介绍了着色和基础着色模型。通过 Blinn-Phong 光照模型，我们可以使物体产生明暗层次、高光和立体感，但它还无法赋予物体真实的表面细节——比如木纹、砖墙、地球的大陆与海洋。

这篇文章将介绍**纹理映射**（Texture Mapping）以及支撑它的核心数学工具——**重心坐标**（Barycentric Coordinates）。

# 纹理映射

假设我们想渲染一个地球模型。我们已经生成了一个球体网格，也引入了光照模型，但渲染出的球体表面只是一颗带有光照效果的"石膏球"——没有大陆的形状、没有海洋的蓝色。

该怎么办？我们手上有一张世界地图（二维图片）。如果能将这张地图"贴"到球体表面，不就能渲染出地球的表面细节了吗？

![纹理映射概念](/images/图形学入门/texture-mapping-concept.png)

在图形学中，这种方法就叫做**纹理映射**（Texture Mapping），这张世界地图就是**纹理贴图**（Texture Map）。我们要解决的核心问题是：如何建立纹理上的每个点与模型表面每个点的对应关系，使纹理完整、准确地呈现在模型上。

为了实现这种映射，图形学引入了 **UV 坐标**。

## UV 坐标

UV 坐标是用于将二维纹理图像映射到三维模型表面的二维坐标系统。因为 3D 空间已经占用了 X、Y、Z 轴，所以使用字母 U 和 V 来表示纹理贴图上的水平和垂直坐标轴。

核心概念：

- **U 和 V**：U 代表图像的水平方向（相当于 X 轴），V 代表图像的竖直方向（相当于 Y 轴）。通过 UV 坐标，可以定位纹理贴图上任意一个点的颜色。
- **坐标范围**：U 和 V 通常被归一化到 $[0, 1]$ 范围内。一般而言左下角是 $(0, 0)$，右上角是 $(1, 1)$。实际工程中根据图形 API 的不同，原点位置可能有所差异（例如 DirectX 左上角为原点）。

因此，对于模型的每一个顶点，它不仅有 $(x, y, z)$ 空间坐标，还有 $(u, v)$ 纹理坐标。这样就能实现纹理像素到模型表面的映射。

你可能会问：模型顶点的 UV 坐标从哪里来？

对于简单几何体，可以通过顶点位置计算得到；但对于复杂的不规则模型，UV 的展平和分配是美术工作者在建模软件中手动完成的。在这里我们只关心 UV 坐标的**使用**，不深究它的**制作**。

你又可能会问：我们只知道三角形三个顶点的 UV 坐标，三角形**内部**的点怎么办？

这就需要用到插值。而在三角形中，有一个非常强大的工具为插值提供了基础——**重心坐标**。

# 重心坐标公式

在讲解重心坐标之前，先要理解什么是**插值**。

**插值（Interpolation）** 是一种通过已知的离散数据点，在范围内推算新数据点的数学方法。

比如一条具有颜色的线段：左端点 $A$ 是红色，右端点 $B$ 是蓝色。我们想知道线段上比例 $t$ 处的颜色，就可以通过线性插值公式来计算：

$$P = A + t(B - A), \quad t \in [0, 1]$$

当 $t = 0$ 时为红色，$t = 1$ 时为蓝色，$t = 0.5$ 时则是半红半蓝的混合色。

那么三角形内的点呢？三角形有三个顶点，仅靠一个参数 $t$ 无法描述平面内任意点的位置——我们需要至少**两个权重**才能唯一确定一个内部点（第三个权重可由前两个推导出来）。

这就是重心坐标的用武之地。假设：

- $\alpha$ 是靠近顶点 $A$ 的权重
- $\beta$ 是靠近顶点 $B$ 的权重

那么 $1 - \alpha - \beta$ 就是靠近顶点 $C$ 的权重，记作 $\gamma$。

![重心坐标](/images/图形学入门/barycentric-coordinates.png)

**$\alpha$、$\beta$、$\gamma$ 就是重心坐标**——一组和为 $1$ 的权重。对于三角形 $ABC$ 内的任意一点 $P$，都有：

$$P = \alpha A + \beta B + \gamma C, \qquad \alpha + \beta + \gamma = 1$$

$\alpha$、$\beta$、$\gamma$ 可以直观地理解为三个顶点对 $P$ 点的"贡献程度"。

那么如何计算这三个权重呢？公式是：

$$\alpha = \frac{S_{\triangle PBC}}{S_{\triangle ABC}}, \qquad \beta = \frac{S_{\triangle PAC}}{S_{\triangle ABC}}, \qquad \gamma = \frac{S_{\triangle PAB}}{S_{\triangle ABC}}$$

其中 $S_{\triangle ABC}$ 表示三角形 $ABC$ 的面积。换句话说：
- $\alpha$ 等于 $P$ 与对边 $BC$ 围成的小三角形面积除以总面积
- $\beta$ 等于 $P$ 与对边 $AC$ 围成的小三角形面积除以总面积
- $\gamma$ 等于 $P$ 与对边 $AB$ 围成的小三角形面积除以总面积

下面我们来推导这个公式。推导之前，需要先引入一个关键的数学工具——**向量的叉乘**。

## 向量的叉乘

向量叉乘（Cross Product，又称向量积、外积）和点乘一样，是向量的一种基本运算。点乘的结果是标量，而叉乘的结果是一个**向量**——同时垂直于两个相乘向量的新向量。

### 几何意义

对于叉乘运算 $\vec{c} = \vec{a} \times \vec{b}$，得到的新向量 $\vec{c}$ 具有以下两个决定性的几何特征：

**1. 方向：绝对垂直**

新向量 $\vec{c}$ 同时垂直于 $\vec{a}$ 和 $\vec{b}$。也就是说，$\vec{c}$ 垂直于 $\vec{a}$ 和 $\vec{b}$ 所在的整个平面。

在图形学中，这正是计算面法线（Face Normal）的最核心手段。有了法线，光照模型（如 Blinn-Phong）才能计算光线与表面的夹角。

**2. 长度：平行四边形的面积**

新向量 $\vec{c}$ 的模长（长度）在几何上恰好等于以 $\vec{a}$ 和 $\vec{b}$ 为邻边构成的平行四边形的面积，也就是以 $\vec{a}$ 和 $\vec{b}$ 为邻边构成的三角形面积的两倍。

$$\|\vec{a} \times \vec{b}\| = \|\vec{a}\| \, \|\vec{b}\| \, \sin\theta$$

其中 $\theta$ 为两向量的夹角。

**特殊情况**：如果 $\vec{a}$ 和 $\vec{b}$ 平行，则 $\theta = 0^\circ$，$\sin 0^\circ = 0$，叉积为零向量——因为此时两向量退化成了一条线，无法围成面积。

### 方向判定

既然 $\vec{c}$ 垂直于平面，那它到底是"朝上"穿出平面，还是"朝下"穿入平面？这取决于**右手定则**（Right-hand Rule）：

![右手定则](/images/图形学入门/right-hand-rule.png)

1. 伸出右手，四指顺着第一个向量 $\vec{a}$ 的方向。
2. 将四指向掌心弯曲，指向第二个向量 $\vec{b}$ 的方向（取夹角小于 $180^\circ$ 的一侧）。
3. 此时，**大拇指所指的方向**就是叉积结果 $\vec{c}$ 的方向。

> **注意顺序**：$\vec{a} \times \vec{b}$ 与 $\vec{b} \times \vec{a}$ 的方向恰好相反（$\vec{a} \times \vec{b} = -(\vec{b} \times \vec{a})$），因为右手要翻转过来。

### 代数计算

在代码实现中，我们不会真的去量角度、画右手，而是直接用向量的分量来算。给定两个三维向量：

$$\vec{a} = (a_x, a_y, a_z), \qquad \vec{b} = (b_x, b_y, b_z)$$

它们的叉积可以通过以下公式逐分量计算：

$$\vec{a} \times \vec{b} = (a_y b_z - a_z b_y,\; a_z b_x - a_x b_z,\; a_x b_y - a_y b_x)$$

这个公式可以借助三阶行列式来记忆：

$$\vec{a} \times \vec{b} = 
\begin{vmatrix}
\mathbf{i} & \mathbf{j} & \mathbf{k} \\
a_x & a_y & a_z \\
b_x & b_y & b_z
\end{vmatrix}
= \mathbf{i}(a_y b_z - a_z b_y) - \mathbf{j}(a_x b_z - a_z b_x) + \mathbf{k}(a_x b_y - a_y b_x)$$

其中 $\mathbf{i}$、$\mathbf{j}$、$\mathbf{k}$ 分别是 $x$、$y$、$z$ 轴的单位向量。沿第一行展开这个行列式，就得到了与上面相同的分量表达式。

从代数公式可以直接验证叉乘的两个关键性质：

- **自身叉乘为零**：$\vec{a} \times \vec{a} = (a_y a_z - a_z a_y,\; a_z a_x - a_x a_z,\; a_x a_y - a_y a_x) = (0, 0, 0) = \vec{0}$。这一性质在后续推导中会反复用到。
- **反交换律**：$\vec{a} \times \vec{b} = -(\vec{b} \times \vec{a})$。

### 重心坐标推导

有了向量叉乘这个工具，我们就可以推导重心坐标公式了。

由 $\alpha = 1 - \beta - \gamma$ 和 $P = \alpha A + \beta B + \gamma C$：

$$P = (1 - \beta - \gamma)A + \beta B + \gamma C$$

$$P = A - \beta A - \gamma A + \beta B + \gamma C$$

将 $A$ 移到等式左边：

$$P - A = \beta(B - A) + \gamma(C - A)$$

写成向量形式：

$$\vec{AP} = \beta \vec{AB} + \gamma \vec{AC}$$

现在我们想要解出 $\beta$。注意到 $\vec{AC} \times \vec{AC} = \vec{0}$，将等式两边同时与 $\vec{AC}$ 做叉乘：

$$\vec{AP} \times \vec{AC} = (\beta \vec{AB} + \gamma \vec{AC}) \times \vec{AC}$$

$$\vec{AP} \times \vec{AC} = \beta (\vec{AB} \times \vec{AC}) + \gamma (\vec{AC} \times \vec{AC})$$

$$\vec{AP} \times \vec{AC} = \beta (\vec{AB} \times \vec{AC}) + \vec{0}$$

等式两边同时取模：

$$\|\vec{AP} \times \vec{AC}\| = \beta \|\vec{AB} \times \vec{AC}\|$$

因此：

$$\beta = \frac{\|\vec{AP} \times \vec{AC}\|}{\|\vec{AB} \times \vec{AC}\|}$$

根据叉乘的几何意义，模长等于两向量围成的平行四边形面积：

- $\|\vec{AP} \times \vec{AC}\| = 2 \cdot S_{\triangle PAC}$
- $\|\vec{AB} \times \vec{AC}\| = 2 \cdot S_{\triangle ABC}$

代入：

$$\beta = \frac{2 \cdot S_{\triangle PAC}}{2 \cdot S_{\triangle ABC}} = \frac{S_{\triangle PAC}}{S_{\triangle ABC}}$$

同理，将 $\vec{AP} = \beta \vec{AB} + \gamma \vec{AC}$ 两边与 $\vec{AB}$ 做叉乘，利用 $\vec{AB} \times \vec{AB} = \vec{0}$，可解出 $\gamma$：

$$\vec{AP} \times \vec{AB} = \gamma (\vec{AC} \times \vec{AB})$$

$$\gamma = \frac{\|\vec{AP} \times \vec{AB}\|}{\|\vec{AC} \times \vec{AB}\|} = \frac{S_{\triangle PAB}}{S_{\triangle ABC}}$$

最后：

$$\alpha = 1 - \beta - \gamma = \frac{S_{\triangle ABC} - S_{\triangle PAC} - S_{\triangle PAB}}{S_{\triangle ABC}} = \frac{S_{\triangle PBC}}{S_{\triangle ABC}}$$

至此，我们完成了重心坐标公式的完整推导。

## 重心坐标的使用

有了重心坐标，就能通过三角形三个顶点的属性，插值出三角形内部任意像素的属性值。

![利用重心坐标UV插值](/images/图形学入门/UV-interpolation.png)

例如，已知三角形三个顶点的 UV 坐标分别为 $\vec{uv}_0$、$\vec{uv}_1$、$\vec{uv}_2$，内部点 $P$ 的重心坐标为 $(\alpha, \beta, \gamma)$，则该点的 UV 坐标为：

$$\vec{uv}_P = \alpha \vec{uv}_0 + \beta \vec{uv}_1 + \gamma \vec{uv}_2$$

同样的插值模式也适用于其他属性：

- **法向量**：$\vec{n}_P = \alpha \vec{n}_0 + \beta \vec{n}_1 + \gamma \vec{n}_2$
- **颜色**：$\vec{c}_P = \alpha \vec{c}_0 + \beta \vec{c}_1 + \gamma \vec{c}_2$
- **世界空间位置**：$\vec{P}_{world} = \alpha \vec{P}_0 + \beta \vec{P}_1 + \gamma \vec{P}_2$

这正是光栅化阶段 GPU 硬件在屏幕空间上做的事：对三角形顶点的每一个属性，用重心坐标做线性插值，然后送入片元着色器。你在 Fragment Shader 里拿到的"插值后法线"和"插值后 UV"，背后就是重心坐标公式在运行。

# 总结

重心坐标是光栅化管线中的核心数学工具，它解决了"三角形内部的像素从哪里获得属性值"这个问题。通过面积比（即 $\alpha : \beta : \gamma$）来加权平均三个顶点的属性，纹理映射、法线插值、颜色平滑过渡等关键渲染步骤才得以实现。
