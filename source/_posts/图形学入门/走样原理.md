# 走样

前面我们在光栅化算法的文章里提到，由于数学中的图像是连续的，但是计算机屏幕是由一个个像素组成的离散的画面，我们无法在计算机屏幕上画出完美的图像。
于是我们采用了一系列光栅化算法来拟合出近似的图形，但是这样画出的图形的边缘始终出现“锯齿”状，我们把这种现象称为“走样”。

![走样对比](/images/图形学入门/aliasing-comparison.png)

比如这张图，我们可以很明显的看出左边的光栅化图像和右边的三角形具有明显的区别。

走样现象在生活中很常见，比如你用摄像机去拍摄显示器，会发现照片上出现一圈圈的摩尔纹，这也是走样导致的。

为了减少走样现象，我们需要先了解走样是为什么产生的，这样我们才能对症下药。

## 时域和频域

要明白走样现象的产生，我们需要先清楚时域和频域的概念。

简单来说，时域描述信号随时间的变化，频域描述信号中包含的不同频率成分。

![时域和频域](/images/图形学入门/time-frequency-domain.png)

通过傅里叶级数，我们可以知道，宇宙中的任何震动和信号，都可以被拆解成一堆简单正弦波（$\sin$ 和 $\cos$）的叠加。

下面这张图可以形象的展示傅里叶级数：

![傅里叶级数](/images/图形学入门/fourier-series.png)

而通过傅里叶变换，我们可以实现任意信号由时域向频域的转换。

下面这张gif图可以让我们直观感受到傅里叶变换的作用：

![傅里叶变换](/images/图形学入门/Fourier_transform_time_and_frequency_domains_(small).gif)

傅里叶变换将函数的时域（红色）与频域（蓝色）相关联。频谱中的不同成分频率在频域中以峰值形式表示。

不只一维函数可以使用傅里叶变换，对于图片等也可以使用傅里叶变换：

![图像的傅里叶变换](/images/图形学入门/image-fourier-transform.png)

如图，左边是一张黑白人像，右边是对图片进行傅里叶变换后得到的频谱图。

在图像的频谱图中：

 - **中心位置（低频）：** 代表图像中变化平缓的大轮廓、大色块。图像的大部分能量都集中在这里。

 - **四周边缘（高频）：** 代表图像中变化剧烈的细节、尖锐的边缘、噪点。

 - **亮度和颜色：** 某个位置越亮，说明图像中对应频率的成分越多。

下面我们对频谱图像进行高通和低通滤波，然后再做傅里叶逆变换，就可以更清晰的理解频谱图：

![高通滤波](/images/图形学入门/high-pass-filter.png)

如上图，如果我们对频谱图进行高通滤波，即过滤掉低频信号，只允许高频信号通过，逆变换得到的人像只有人像边缘画面剧烈变换的部分的信号。

![低通滤波](/images/图形学入门/low-pass-filter.png)

如上图，如果我们对频谱图进行低通滤波，即过滤掉高频信号，只允许低频信号通过，逆变换得到的人像有全部画面，但是变得非常模糊。

## 点乘与卷积

### 点乘

![点乘](/images/图形学入门/dot-product.png)

$$y(t) = f(t) \cdot g(t)$$

点乘就是对位相乘：两个函数在同一个位置上的值直接相乘，得到一个新的函数。

举个具体的例子，假设我们有一个一维信号 $f$ 和一个采样函数 $s$（冲激阵列的简化版）：

$$f = [3,\ 5,\ 2,\ 8,\ 4,\ 6]$$

$$s = [1,\ 0,\ 1,\ 0,\ 1,\ 0]$$

点乘就是对位相乘：

$$f \cdot s = [3 \times 1,\ 5 \times 0,\ 2 \times 1,\ 8 \times 0,\ 4 \times 1,\ 6 \times 0] = [3,\ 0,\ 2,\ 0,\ 4,\ 0]$$

可以看到，乘 1 的位置原值保留，乘 0 的位置直接被清零——这就是采样的数学本质。

在时域上，点乘经常用于信号采样：

形象一点比喻，比如我们有一张连续的图像，点乘一个由无数个’孤立针尖’组成的采样网格（冲激阵列）。针尖所在的地方，乘以 1，原图颜色露出来；其余地方没有针尖，乘以 0，信息直接被抹杀。这一刀切下去，连续的现实世界就变成了离散的像素点。

在频域上，点乘经常用于滤波：

形象一点比喻，图像的频谱图摆在面前，我们拿一个圆形的数字面具扣上去：圆圈内部全打 1 分（保留），圆圈外部全打 0 分（舍弃）。由于图像的边缘、锯齿等细节都在外圈（高频），面具一扣，对位一乘，外圈的高频瞬间消失。整个过程不需要滑动，一瞬间就完成了频率的清洗。

### 卷积

![卷积](/images/图形学入门/convolution.png)

$$(f * h)(t) = \int_{-\infty}^{\infty} f(\tau)h(t-\tau)d\tau$$

公式看着复杂，但卷积的本质其实很简单：拿一个小模板（卷积核）在数据上滑动，每到一个位置就对覆盖区域做加权求和。

下面通过一个具体的 1D 例子，一步步感受卷积的计算过程。

假设我们有一个一维信号 $f$ 和一个长度为 3 的均值模糊核 $h$：

$$f = [1,\ 3,\ 2,\ 4,\ 5]$$

$$h = [\tfrac{1}{3},\ \tfrac{1}{3},\ \tfrac{1}{3}]$$

卷积核 $h$ 从信号 $f$ 的左侧开始，一步一步向右滑动。每到一个位置，把核覆盖到的信号值乘以对应的权重，然后求和：

**第 1 步**（核的最右端对齐 $f$ 的第一个元素）：

$$(f * h)[0] = 1 \times \tfrac{1}{3} \approx 0.33$$

**第 2 步**（核向右滑动一格）：

$$(f * h)[1] = 1 \times \tfrac{1}{3} + 3 \times \tfrac{1}{3} \approx 1.33$$

**第 3 步**（核完全进入，覆盖三个元素）：

$$(f * h)[2] = 1 \times \tfrac{1}{3} + 3 \times \tfrac{1}{3} + 2 \times \tfrac{1}{3} = 2.0$$

**第 4 步**：

$$(f * h)[3] = 3 \times \tfrac{1}{3} + 2 \times \tfrac{1}{3} + 4 \times \tfrac{1}{3} = 3.0$$

**第 5 步**：

$$(f * h)[4] = 2 \times \tfrac{1}{3} + 4 \times \tfrac{1}{3} + 5 \times \tfrac{1}{3} \approx 3.67$$

最终结果：

$$f * h \approx [0.33,\ 1.33,\ 2.0,\ 3.0,\ 3.67]$$

对比原始信号 $[1,\ 3,\ 2,\ 4,\ 5]$ 和卷积结果 $[0.33,\ 1.33,\ 2.0,\ 3.0,\ 3.67]$，可以看到原本突兀的跳变（比如 $1$ 骤升到 $3$）被"抹平"了，相邻值之间的过渡变得更缓和——这就是卷积的模糊效果。

在时域（空间域）上，卷积经常用于图像模糊：

形象一点理解，我们拿一个 $3 \times 3$ 的高斯模糊核，在图像的每一个像素上滑过去。每到一个地方，就把当前像素和周围邻居的颜色按照权重混合在一起。这种’滑动抄作业’的后果就是信息的扩散——原本锐利的边缘被揉碎、晕开，画面就变模糊了。

在频域上，卷积解释了采样为什么会导致频谱复制：

要理解这一点，需要先了解冲激函数（$\delta$ 函数）的卷积特性。$\delta$ 函数可以理解为在某个位置上值为"无限大"、其余位置为 0 的尖峰，它有一个非常优雅的性质：

$$f(t) * \delta(t) = f(t) \quad \text{（和位置 0 的冲激做卷积，等于原函数不动）}$$

$$f(t) * \delta(t - T) = f(t - T) \quad \text{（和位置 T 的冲激做卷积，等于把原函数搬到 T）}$$

换句话说，**冲激函数就像一个"搬运工"——和它做卷积，会把原函数搬运到冲激所在的位置**。

你可能会疑惑：前面点乘的例子中采样函数用的是 $[1, 0, 1, 0, ...]$，为什么到了 $\delta$ 函数这里就变成"无限大"了？

这两个其实并不矛盾——$[1, 0, 1, 0, ...]$ 是离散视角下的简化模型，每个采样点直接乘 1，直观好用。但 $\delta$ 函数是严格的连续数学描述。在连续域中，采样是在宽度趋近于零的瞬间完成的，$\delta$ 函数必须同时满足两个条件：① 只在一点有非零值（宽度为 0）；② 曲线下方的总面积等于 1。

宽度趋于零，面积又要保持为 1，高度自然趋于无穷大。可以这样想象：把一个宽度为 $\Delta$、高度为 $1/\Delta$ 的窄矩形不断压窄，$\Delta \to 0$ 时宽度趋于 0、高度趋于无穷，但面积始终是 1——这就逼近了 $\delta$ 函数。

面积等于 1 才是关键所在，它赋予了 $\delta$ 函数**筛选性质**：

$$\int_{-\infty}^{\infty} f(t)\,\delta(t - a)\,dt = f(a)$$

用 $\delta(t-a)$ 去乘 $f(t)$ 再积分，恰好能"筛"出 $f(t)$ 在 $a$ 点的值。如果高度是 1 而宽度为 0，面积就变成了 0，什么也筛不出来。

更重要的是，正是因为 $\delta$ 函数的面积为 1，冲激阵列的傅里叶变换才恰好还是冲激阵列——这是后面推导频谱复制的数学基础，用 $[1,0,1,0,...]$ 的离散简化模型是推导不出这个结论的。

而冲激阵列就是一系列等间距的 $\delta$ 函数：

$$\text{冲激阵列} = \delta(t) + \delta(t - T) + \delta(t - 2T) + \dots$$

因此，用任意函数去卷积冲激阵列，就等于在每一个冲激位置各复制一份原函数，然后全部叠加：

$$f(t) * \text{冲激阵列} = f(t) + f(t - T) + f(t - 2T) + \dots$$

举个简化的例子。假设原始频谱只有 $[a, b, c]$ 三个值，冲激阵列的频谱每隔 4 个位置有一个尖峰：

```
原始频谱:        [a,  b,  c]
冲激阵列的频谱:  [1,  0,  0,  0,  1,  0,  0,  0,  ...]

δ(0) 处的复制:   [a,  b,  c,  0,  0,  0,  0,  ...]
δ(4) 处的复制:   [0,  0,  0,  0,  a,  b,  c,  ...]

叠加后的结果:    [a,  b,  c,  0,  a,  b,  c,  ...]
```

一目了然——原始频谱被完整地复制到了每个冲激所在的位置，形成周期性的频谱副本。

现在回到采样问题：当我们在时域对信号进行采样（即点乘冲激阵列）时，根据对偶性（时域点乘 $\Leftrightarrow$ 频域卷积），在频域上等价于原始频谱与冲激阵列的频谱做卷积。而冲激阵列的傅里叶变换恰好还是冲激阵列（间距变为原来的倒数），结合 $\delta$ 函数的"搬运"特性，频谱就这样被周期性复制了。

这就是为什么采样会在频域产生一连串频谱副本——它不是巧合，而是冲激函数"复制粘贴"特性在频域的必然体现。

### 时域与频域的对偶性

最后，有一个非常重要的结论：

- **时域的点乘 $\Leftrightarrow$ 频域的卷积**
- **时域的卷积 $\Leftrightarrow$ 频域的点乘**

这两条对偶关系是信号处理的基石：在一个域里做乘法，等价于在另一个域里做卷积。

我们可以用一个表格来总结点乘和卷积在两个域中的作用：

| 操作 | 时域作用 | 频域作用 |
|------|---------|---------|
| 点乘 | 采样（离散化） | 滤波（去除频率成分） |
| 卷积 | 模糊（平滑化） | 频谱复制（周期性搬移） |

理解了这个对偶性，走样的逻辑链就完整了——时域采样（点乘冲激阵列）$\rightarrow$ 频域卷积（频谱复制）$\rightarrow$ 采样频率过低 $\rightarrow$ 频谱副本重叠 $\rightarrow$ 高频伪装成低频 $\rightarrow$ 走样。

这个结论的证明涉及傅里叶变换的性质，这里不再展开。

## 采样

经过了前面的铺垫，我们终于可以解释为什么会发生走样了。

![采样](/images/图形学入门/sampling.png)

如图，我们对一个函数图像，也就是信号进行采样，在时域平面上，这对函数图像点乘了一个冲激阵列，在频域平面上，这对函数图像进行了卷积。

最终，时域平面上我们得到了一些离散的点，而频域平面上，我们对频谱进行了复制。

但是，我们采样的频率变化会导致最终得到的图像的变化。

时域平面上，采样频率的变化很简单，会导致最后得到点的多少的变化，频率变高，采样点越密集；频率变低，采样点越稀疏。

在频域平面上，采样频率的变化会导致频谱副本的间距变化，时域采样频率越高，频域中的频谱副本间隔越大；采样频率越低，副本挤得越近，更容易重叠。

![频谱重叠](/images/图形学入门/spectrum-overlap.png)

频谱重叠意味着多个频率成分落在了同一个位置，导致高频信息伪装成低频信息，从而无法正确恢复原始图像，这种现象就是走样（aliasing）。

现在，我们解释一下图像边缘锯齿产生的原因：

光滑的边缘属于高频变化，它包含大量高频。如果采样率不足，高频信息就会被错误的解释为低频信息，边缘就会被错误重建成锯齿状。

明白了走样的原理，我们就可以针对性的进行反走样了。
